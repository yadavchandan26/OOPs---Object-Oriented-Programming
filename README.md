# Object-Oriented Programming

A learning repository for exploring the core ideas behind object-oriented programming (OOP). The examples in this repository are intended to build understanding step by step as the project grows.

## What Is OOP?

Object-oriented programming is a way to organize software around **objects**. An object combines data (its state) with functions that operate on that data (its behavior). Objects are created from **classes**, which describe the data and behavior their instances share.

## Core Concepts

- **Classes and objects** — A class is a blueprint; an object is an instance of that class.
- **Attributes and methods** — Attributes store an object's data, while methods define what it can do.
- **Encapsulation** — Keep related data and behavior together, and control how an object's state is accessed or changed.
- **Inheritance** — Build a class from another class to reuse or specialize its behavior.
- **Polymorphism** — Use a shared interface with different implementations, so different object types can be handled consistently.
- **Abstraction** — Expose the essential operations while hiding unnecessary implementation details.

## Goals

- Learn OOP vocabulary and design principles.
- Write small, readable examples that demonstrate each concept.
- Practice modeling real-world ideas as cooperating objects.
